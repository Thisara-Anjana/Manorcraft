# Manorcraft Luxury Services

"Create a modern, luxury-style web application for a premium home service and repair brand called 'Manorcraft'. The primary color palette should be elegant (deep navy blue, gold/brass accents, and clean white).

Build a Landing Page with:

A responsive Navigation Bar with links: 'Home', 'Book a Service', 'Admin Login', and 'Technician Login'.

A Hero Section with a premium headline: 'Elite Home Maintenance & Craftsmanship', a subheadline about verified experts in Sri Lanka, and a clear 'Book Now' Call to Action button.

A 'Our Services' grid highlighting Plumbing, Electrical, Masonry, and AC Repair using Lucide React icons."
